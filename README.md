### **Description :bulb:**
- *This is an implementation of classic 2048 game using C#, .NET, and MAUI, built with scalable architecture and modern tools provided by the platform.*
---
### **Key features :key:**
 - **:pushpin:Undo implementation** *- memento pattern has been used to provide game state history*
 - **:pushpin:Flexible game design** *- core mechanics support extensions, makes it easy to add new game modes*
 - **:pushpin:Decoupled logic** *- game core is separated from the UI, makes game's architecture scalable*
 - **:pushpin:Tile themes** *- dynamic theme change to customize experience*
 - **:pushpin:Animations** *- smooth transitions of tiles provided by modern tools*
 - **:pushpin:Cross-platform support** *- thanks to MAUI, the game can be run on different platforms*
